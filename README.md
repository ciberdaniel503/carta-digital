# 🍽️ Carta Digital

Proyecto de desarrollo web enfocado en la creación de una carta digital para presentar información de manera organizada y accesible desde un navegador.

## 🎯 Objetivo

Crear una experiencia digital sencilla que facilite la consulta de una carta desde una computadora o dispositivo móvil.

## 🛠️ Tecnologías

- **HTML:** estructura del contenido.
- **CSS:** diseño y presentación visual.
- **JavaScript:** interactividad, si está implementada en el proyecto.
- **Git y GitHub:** control de versiones y alojamiento del código.

## ✨ Características

- Presentación digital de la información.
- Interfaz web organizada.
- Acceso desde un navegador.
- Posibilidad de consultar el contenido desde diferentes dispositivos, según el diseño implementado.

## 🌐 Demo en línea

Puedes probar el proyecto publicado con GitHub Pages:

👉 **[Abrir Carta Digital](https://ciberdaniel503.github.io/carta-digital/)**

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio:

   ```bash
   git clone https://github.com/ciberdaniel503/carta-digital.git
   ```

2. Entra en la carpeta:

   ```bash
   cd carta-digital
   ```

3. Abre el archivo `index.html` en tu navegador, si ese es el archivo principal del proyecto.
